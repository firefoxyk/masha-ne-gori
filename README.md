# Маша, не гори

Подготовка репозитория проекта игры «Маша, не гори».

Приложение находится в разработке. Подробная документация появится на следующих этапах.

## Запуск

Для работы нужны Node.js 20.19+ или 22.12+ и npm (проверено с Node.js 26 и npm 11). Установите Node.js вместе с npm с [официального сайта](https://nodejs.org/).

В терминале в папке проекта выполните:

```bash
npm install
npm run dev
```

Откройте в браузере адрес, который покажет Vite (обычно http://localhost:5173/). Чтобы остановить сервер, нажмите Ctrl+C в терминале.

Для проверки TypeScript и создания production-сборки:

```bash
npm run build
```
