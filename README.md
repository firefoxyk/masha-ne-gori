# Маша, не гори

Подготовка репозитория проекта игры «Маша, не гори».

Приложение находится в разработке.

## Запуск

Для работы и проверок нужны npm и Node.js версии 22.12 или новее в ветке 22, версии 24 либо версии 26 или новее (проверено с Node.js 26 и npm 11). Установите Node.js вместе с npm с [официального сайта](https://nodejs.org/).

В терминале в папке проекта выполните:

```bash
npm install
npm run dev
```

Откройте в браузере адрес, который покажет Vite (обычно http://localhost:5173/). Чтобы остановить сервер, нажмите Ctrl+C в терминале.

Для проверки TypeScript и создания production-сборки:

```bash
npm run build
```

## Автоматические проверки

После `npm install` выполните:

```bash
npm test
```

Vitest проверяет отдельные части приложения; сейчас он проверяет начальное состояние игры и его границы. Добавляйте тесты в `src/` рядом с кодом или в `tests/unit/` с именами `*.test.ts`, `*.spec.ts` (также поддерживаются `.tsx`). Если тестов нет, команда сообщает об этом и завершается успешно. Для режима разработки используйте `npm run test:watch`.

Playwright проверяет приложение в браузере. Один раз установите Chromium для текущей версии Playwright, затем запускайте тест:

```bash
npx playwright install chromium
npm run test:e2e
```

Playwright сам запускает локальный сервер на порту 4173 и проверяет название и статус стартовой страницы. Порт должен быть свободен. Это не заменяет проверку на настоящем Android.

## Структура проекта

- `src/` — интерфейс приложения: компоненты React и стили.
- `src/game/` — будущая игровая логика.
- `src/content/` — игровые события и тексты.
- `src/assets/` — изображения и другие материалы игры.
- `src/storage/` — код сохранения прогресса.
- `tests/` — тесты проекта.
- `docs/` — документация проекта.

В ещё пустых каталогах файлы `.gitkeep` сохраняют структуру в Git; содержимое будет добавляться на следующих этапах.
